# garfio

Memecoins backed by RWAs on Stellar — Robinhood-style economic exposure, meme-coin UX.

## Plan (start here)

Interactive infrastructure plan (B/W, Geist, no branding yet):

```bash
# from repo root
python3 -m http.server 4173 --directory plan
# open http://localhost:4173
```

Or open [`plan/index.html`](./plan/index.html) directly in a browser.

The artifact covers:

1. Product idea (meme front · RWA back)
2. Issuer vs wrapper vs hybrid model
3. Interactive end-to-end user flow
4. Layered architecture + stack
5. Probable monthly costs (MVP / Growth / Issuer)
6. Build phases and risks
